# Product Service

REST microservice exposing CRUD operations for products, backed by an in-memory H2 database.

## Tech stack

- **Java 21** (virtual threads enabled)
- **Spring Boot 3.5** — Spring Web, Spring Data JPA, Bean Validation
- **H2** in-memory database (schema auto-generated by Hibernate)
- **springdoc-openapi** — OpenAPI 3 spec + Swagger UI
- **Maven** (wrapper included)
- **JUnit 5, Mockito, AssertJ, MockMvc** for testing

## Project structure

```
src/main/java/com/example/productservice/
├── controller/   REST endpoints
├── service/      business logic
├── repository/   Spring Data JPA repositories
├── entity/       JPA entities
├── dto/          request/response records
├── mapper/       DTO <-> entity mapping
└── exception/    domain exceptions + global handler (RFC 7807 ProblemDetail)
```

## Running

```bash
./mvnw spring-boot:run
```

The service starts on `http://localhost:8080`. Data lives in memory and is reset on every restart.

| Resource | URL |
|---|---|
| Swagger UI | http://localhost:8080/swagger-ui.html |
| OpenAPI spec (JSON) | http://localhost:8080/v3/api-docs |

## API

Base path: `/api/v1/products`

| Method | Path | Description | Responses |
|---|---|---|---|
| POST | `/` | Create a product | 201, 400, 409 |
| GET | `/{id}` | Get a product by id | 200, 404 |
| GET | `/?page=0&size=20&sort=name,asc` | List products (paginated, sortable) | 200 |
| PUT | `/{id}` | Replace a product | 200, 400, 404, 409 |
| DELETE | `/{id}` | Delete a product | 204, 404 |

Request body:

```json
{
  "name": "Wireless Mouse",
  "description": "Ergonomic 2.4GHz wireless mouse",
  "price": 19.99,
  "stock": 10,
  "sku": "MS-001"
}
```

`name`, `price`, `stock` and `sku` are required; `sku` must be unique. Errors are returned as `application/problem+json`.

## Postman

Import `postman/product-service.postman_collection.json`. The `baseUrl` collection variable defaults to `http://localhost:8080`; **Create product** stores the new id in `productId` for the subsequent requests.
